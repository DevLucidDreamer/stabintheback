# Stab in the Back

Windows x64 · 4인 협동과 배신 게임 · 1.0.0

## 실행

ZIP 전체를 압축 해제하고 `StabInTheBack.exe`를 실행하세요. 실행 파일만 따로 옮기지 마세요. 같은 폴더의 `StabInTheBack_Data`, `UnityPlayer.dll` 및 함께 제공된 파일이 필요합니다.

한 명이 방을 만들고 나머지 세 명은 방 코드로 참가합니다. 네 명 모두 같은 버전으로 실행하세요. 온라인 방 연결에는 인터넷과 Unity Relay 서비스 연결이 필요합니다. 대기실에 네 명이 모이면 원정이 시작됩니다.

## 스태미나

화면 하단 바가 달리기 스태미나입니다. 최대 약 4.5초간 달릴 수 있습니다. 달리기를 멈추면 1.2초 뒤부터 회복하며, 비어 있는 상태에서 완전히 회복하는 데 약 6초가 걸립니다.

완전히 소진했을 때는 30% 이상 회복한 뒤 Shift를 놓았다가 다시 눌러야 달릴 수 있습니다. 제자리에서 Shift만 누르는 것으로는 소모되지 않습니다.

## 마검과 소유권

무기는 최대 세 개까지 보유할 수 있습니다. 추가 무기를 조준하고 우클릭하면 기존 무기를 버리지 않고 획득합니다. 네 번째 무기는 주울 수 없으므로 먼저 장착 무기를 G로 내려놓으세요.

핫바 없이 마우스 휠로 전환합니다. 현재 장착한 한 자루만 손에 표시되며, 전환 시 무기 이름이 잠깐 나타납니다. 공격 도중 빠르게 전환해 공격 간격을 줄일 수는 없습니다.

성배병·폐광 랜턴·숨겨진 냉동참치 마검은 맵을 이동해도 같은 접속자가 계속 보유하고, 장착 상태도 이어집니다. 사망하면 보유한 무기를 모두 떨어뜨리므로 다른 플레이어가 가져갈 수 있습니다. 방을 종료하면 소유권 기록이 초기화됩니다. 대기실 연습용 무기는 원정 마검과 별개입니다.

## 원정

기존 대기실 → 돌 신전 → 폐광 돌다리 → 지하 제단 → 대기실 순서로 진행합니다.

- 돌 신전: 발판과 레버로 길을 열고 성배병을 찾습니다.
- 폐광 돌다리: 네 명이 석재를 나르며 다리를 복구하고 폐광 랜턴을 찾습니다. 숨겨진 마검도 어딘가에 있습니다.
- 지하 제단: 조각상과 문자 문양을 살펴보고 마지막 의식을 완성합니다.

맵의 문양과 구조가 단서입니다. 사망 시 WASTED가 표시되고 진행도에 따른 지점에서 부활합니다.

## 오디오와 에셋

ESC 설정에서 전체 음량·효과음·배경음악을 조절할 수 있습니다. 플레이어 타격음은 유지하고 명중 문구는 제거했습니다.

외부 텍스처와 오디오의 출처는 함께 제공하는 `THIRD_PARTY_NOTICES.txt`와 게임 데이터의 StreamingAssets/Licenses에 기록되어 있습니다. 성배병과 기존 모델은 프로젝트 제공 에셋이며, 폐광 랜턴은 프로젝트에서 제작한 모델입니다.

## 이번 빌드의 확인 범위

기능 반영 후 자동 검사 및 테스트용 빌드는 통과했습니다. 사용자 요청에 따라 추가 4인 네트워크 실동작 검증은 생략하고 이 Windows 빌드를 생성했습니다. 이번 무기 소유권·전환 변경의 인터넷 Relay 및 음성 연결 실기기 검증은 포함하지 않습니다.

## 개발 프로젝트

Unity 6000.3.15f1을 사용합니다. `Assets/Scenes/MainTitle.unity`에서 시작합니다. 원정 씬 생성 메뉴는 Tools/Stage에 있습니다. 최종 빌드의 진입점은 `FinalBuildPipeline.BuildBatch`이며 `-skip-checks`는 생성된 씬을 그대로 사용하고 추가 검사를 생략합니다.
