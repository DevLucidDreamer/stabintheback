# Stab in the Back 1.0.0 출시 체크리스트

## 자동 검사 및 패키징

Unity 메뉴에서 `Tools > Release > Validate Release (출시 점검)`을 실행한다.
Windows 배포본은 `Tools > Release > Build Windows x64 (출시 빌드)`로 만든다.
배포할 파일은 `Builds/Releases/StabInTheBack-Windows-x64-v1.0.0.zip`이다.
`Builds/Windows` 폴더를 직접 압축하지 않는다. 그 폴더에는 배포 금지 디버그 자료가 생성될 수 있다.

## 출시 전 수동 테스트

- 서로 다른 Windows 사용자 또는 서로 다른 PC에서 호스트와 클라이언트를 실행한다.
- 1명, 2명, 4명, 최대 8명으로 방 생성·코드 참가·준비·스테이지 전환을 확인한다.
- 잘못된 코드, 만료된 코드, 가득 찬 방, 호스트 종료 시 오류 안내와 타이틀 복귀를 확인한다.
- 로비 → 저주받은 요새 → 캠핑장 → 결과/재시작 흐름을 3회 이상 반복한다.
- 각 스테이지의 승리·패배·사망·부활/관전·상호작용·무기 획득과 공격을 확인한다.
- V Push-to-Talk, M 음소거, 마이크 미연결, Windows 마이크 권한 거부 상태를 확인한다.
- 음성 연결 중 네트워크를 10초 끊었다 복구하고 로그 폭주 없이 재연결되는지 확인한다.
- 1280×720, 1920×1080, 창 모드 크기 변경에서 UI 잘림과 입력 이상이 없는지 확인한다.
- 새 Windows PC에서 ZIP만 풀어 실행하고 아이콘·고지문·첫 실행 방화벽 안내를 확인한다.

## 배포 운영 확인

- Unity Dashboard의 Production 환경에서 Authentication, Relay, Vivox가 활성화되어 있는지 확인한다.
- Relay/Vivox 사용량 한도와 결제/알림 수신자를 확인한다.
- 배포 채널에 버전 `1.0.0`, 지원 연락처, 알려진 문제, 최소 사양을 기록한다.
- `docs/asset_provenance.md`의 확인 필요 항목을 권리 보유자가 검토하고 서명한다.
