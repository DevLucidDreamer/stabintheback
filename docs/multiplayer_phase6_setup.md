# Multiplayer Phase 6 Setup — Stage Transition + Stage 2

Phase 6 (part 1) goal: when the shared checklist is complete and a player steps out the main door, advance to the next stage. Also adds a second stage (Campground).

## Design

- `EscapeZone` (NetworkBehaviour + trigger) sits just outside the main door.
  - A local player entering the trigger checks `CampChecklistManager.IsComplete()`.
  - If complete → `CmdTryEscape` (requiresAuthority = false) → server double-checks and calls `NetworkManager.ServerChangeScene(nextScene)`.
  - If not complete → local on-screen hint "준비물을 모두 챙겨야 나갈 수 있다!".
- Mirror keeps the `NetworkManager` across scene changes (dontDestroyOnLoad) and re-spawns players at the new scene's `NetworkStartPosition`s (autoCreatePlayer). So Stage 2 needs only environment + spawn points + its own checklist/weapon managers + an escape zone — no NetworkManager.
- Stage 2 (`Stage2_Campground`) is generated by a builder and reuses the Phase 3/4 setup (checklist + weapons). Its escape zone loops back to Stage 1 (final stage of this demo).

## Files

- `Assets/Scripts/EscapeZone.cs` (new)
- `Assets/Scripts/CampChecklistManager.cs` — added `IsComplete()`.
- `Assets/Scripts/Editor/NetworkPhase6Setup.cs` (new) — escape zone placement + build-settings helper.
- `Assets/Scripts/Editor/Stage2Builder.cs` (new) — builds the campground scene end-to-end.

## Manual Unity Editor steps

1. **Build Stage 2**: `Tools > Stage > Build Stage 2 (Campground)`.
   - Creates `Assets/Scenes/Stage2_Campground.unity` with environment, spawn points, collectibles (장작/마시멜로/부탄가스/랜턴/낚싯대), 마검 2종(도끼/바비큐집게), checklist + weapon managers, and a looping escape zone.
   - Adds both scenes to Build Settings.
2. **Stage 1 escape**: open `NetworkDemo.unity`, run `Tools > Multiplayer > Phase 6 > Setup Escape (Stage1 -> Stage2)`, then Ctrl+S.
   - (Make sure Phase 2–5 setups were already run in NetworkDemo.)

## Test

1. Host + ParrelSync client on `NetworkDemo`.
2. Try to leave through the front door before finishing → "준비물을 모두 챙겨야 나갈 수 있다!".
3. Collect all items (co-op), then step out the door → both clients load `Stage2_Campground` and respawn there.
4. In the campground, finish its checklist and reach the exit zone → loops back to Stage 1.
