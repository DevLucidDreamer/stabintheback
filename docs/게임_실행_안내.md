# 게임 실행 안내 — 캠핑장 바베큐

> 갱신: 2026-08-09 · Unity 6000.3.15f1 · URP 17.3 · Mirror

---

## 1. 게임 목표

한 판은 네 단계로 흘러간다. 전부 **서버 권한**으로 진행되고, 플레이어는 어느 단계든 서로를 죽일 수 있다.

| 단계 | 화면 | 해야 할 일 |
|---|---|---|
| **① 낮 (Gathering)** | 밝은 대낮 | 캠핑장에 흩어진 **장작 4 · 고기 4 · 야채 3**을 모은다 |
| **② 해질녘 (Dusk)** | 해가 넘어가는 9초 | 자동 전환. 되돌아가지 않는다 |
| **③ 노을 (Cooking)** | 붉은 저녁 하늘 | **화로에 장작을 전부 넣어 불을 피우고**, 그릴에 고기·야채를 올려 굽는다 |
| **④ 완성 (Feast)** | 승리 연출 | 7개를 다 구워내면 끝. 9초 뒤 대기실로 돌아간다 |

**재료는 팀 공용 재고다.** 아무나 주우면 모두의 재고가 되고, 아무나 그 재고를 꺼내 쓴다.
협동은 재고가 강제하고, 배신은 무기(마검)가 담당한다 — 남이 다 구워 놓은 걸 가로채거나,
굽고 있는 사람을 때려눕히고 자리를 차지할 수 있다.

### 굽기 규칙

- 그릴은 **4칸**. 좌클릭 한 번이 상황에 맞는 일 하나를 한다.
  1. 다 익은 게 있으면 **꺼낸다** (가장 급한 일)
  2. 탄 게 있으면 **치운다**
  3. 빈칸이 있으면 **올린다** (고기 먼저, 없으면 야채)
- 올린 뒤 **9초**면 알맞게 익고, 거기서 **11초**를 더 두면 **탄다**.
- 칸 위에 익는 정도가 %로 뜨고, 탈 때가 가까우면 글자가 깜빡인다.
- 태워도 판이 막히지 않는다 — 탄 재료는 재고로 되돌아가 다시 구울 수 있다.

## 2. 조작

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 점프 |
| 마우스 | 시점 |
| **좌클릭** | 빈손이면 줍기·사용 / 무기를 들었으면 휘두르기 |
| **우클릭** | 무기를 든 채로 줍기·사용 (화로·그릴 포함) |
| **G** | 든 무기 내려놓기 |
| **E** | 재료 체크리스트 클립보드 |
| **Tab** | 방 옵션 (대기실, 호스트 전용) |

무기는 **한 방이면 즉사**다. 죽으면 스폰 지점에서 즉시 부활하고, 들고 있던 무기는 죽은 자리에 떨어진다.

## 3. 씬을 다시 만드는 법

맵과 UI는 전부 에디터 스크립트가 생성한다. **씬을 손으로 고치지 말고 빌더 스크립트의 좌표를 고치고 다시 실행한다.**

### 한 번에 전부

```
Tools > Setup > Build Everything (전체 다시 만들기)
```

순서대로 실행된다: TMP 폰트 → 무기 프리팹 → 플레이어 애니메이션 → 래그돌 → 타이틀 → 캠핑장 → 대기실.
마지막에 Build Settings가 **타이틀 → 대기실 → 캠핑장** 순서로 정리된다.

### 부분만

| 메뉴 | 하는 일 |
|---|---|
| `Tools > Lobby > Build Lobby` | 대기실 씬 재생성 + Build Settings 정리 |
| `Tools > Stage > Build Stage 2 (Campground)` | 캠핑장 씬 재생성 (재료·화로·그릴 포함) |
| `Tools > Stage > Rebuild Camp Props (씬 유지)` | 배치는 두고 프롭 모양만 갱신 |
| `Tools > Setup > Rebuild Prefabs Only (씬 유지)` | 무기·캐릭터 프리팹만 다시 굽기 |
| `Tools > Multiplayer/Phase 3 > Setup Camp Game Sync` | 재료를 손으로 더 놓은 뒤 ID 다시 매기기 |
| `Tools > Fonts > Set Jalnan2 SDF as TMP Default` | HUD 한글이 네모로 나올 때 |

> **재료를 손으로 추가·삭제했다면** 반드시 `Setup Camp Game Sync`를 실행할 것.
> 재료마다 고유 ID가 있어야 서버가 획득을 확정할 수 있고,
> 목표 개수는 씬에 실제로 놓인 개수로 자동 보정된다.

## 4. 플레이 방법

1. `Assets/Scenes/MainTitle.unity`를 열고 Play
2. **게임 시작 → 방 열기** — 화면 왼쪽 위에 7글자 방 코드가 뜬다
3. 친구는 **게임 시작 → 참가하기**에 코드를 입력하거나, 같은 공유기면 **빠른 참가**
4. 대기실에서 호스트가 **Tab**으로 정원을 정한다 (1~8명)
5. 정원이 차면 5초 카운트다운 후 캠핑장으로 출발

혼자 확인하려면 대기실에서 **Tab → 정원 1**로 내리면 바로 출발한다.

## 5. 구조 메모

### 런타임 핵심

| 파일 | 역할 |
|---|---|
| `CampGameManager.cs` | 페이즈·재고·그릴 칸을 전부 들고 있는 서버 권한 매니저 |
| `DayNightController.cs` | 진행도(0→1)만 보고 해·환경광·안개·하늘을 보간 |
| `Firepit.cs` / `BarbecueGrill.cs` | 상호작용 창구 + 연출. 판정은 매니저가 한다 |
| `GameHud.cs` | 런타임에 만드는 TMP 캔버스 하나. 모든 화면 글자가 여기로 모인다 |
| `CampHud.cs` / `LobbyHud.cs` | 각 씬의 상태를 GameHud에 옮겨 적는 표시 전용 컴포넌트 |

화로와 그릴이 각자 `NetworkIdentity`를 갖지 않는 이유: `Interactable`이 MonoBehaviour라
`NetworkBehaviour`를 겸할 수 없고, 상태를 한 곳에 모아 두면 늦게 접속한 사람에게 넘겨줄 것도 한 덩어리로 끝난다.

### UI

화면 글자는 **전부 TMP**다 (`Jalnan2 SDF`). IMGUI(`OnGUI`)는 남아 있지 않다.
런타임에 만드는 글자는 **TMP 기본 폰트**를 쓰므로, 기본 폰트가 `Jalnan2 SDF`로 지정되어 있어야 한다
(빌더가 자동으로 지정하고, 지정이 풀렸으면 씬의 팻말에서 폰트를 빌려 오는 폴백이 있다).

### 빌드에 들어가는 씬

`MainTitle` → `Lobby` → `Stage2_Campground` 셋뿐이다.
`NetworkDemo` · `Demo` · `SampleScene` · `Assets/_Recovery/*`는 개발 초기 실험용이라 빌드에서 제외했다.
이 씬들은 삭제된 옛 스크립트를 참조하므로 열면 "missing script" 경고가 뜬다 — 정상이다.
