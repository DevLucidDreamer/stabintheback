## 1. 이 공간의 목적

대기실은 "친구가 다 모일 때까지 기다리는 로딩 화면"이 아니다.
**게임을 켠 순간부터 이 게임이 무슨 게임인지 몸으로 알게 만드는 첫 번째 방**이다.

| 목적 | 어떻게 |
|---|---|
| ① 게임의 정체성을 1초 만에 전달 | 숲 들판 한가운데 나무 식탁, 그 위에 **냉동참치 한 마리**. 설명 없이 "아 병맛이구나"가 온다 |
| ② 핵심 재미를 미리 체험 | 참치를 들면 그게 **마검**이다. 대기실에서 이미 원킬·리스폰·뺏고 뺏기기가 돌아간다 |
| ③ 조작 학습 | 줍기 / 휘두르기 / 내려놓기를 허수아비로 안전하게 연습 |
| ④ 신경전의 시작 | 마검은 **딱 한 자루**. 출발 전부터 "누가 저걸 쥐고 갈 것인가"가 시작된다 |
| ⑤ 출발 합의 | 전원이 출발 발판에 올라서야 첫 스테이지로 넘어간다 |

> **설계 원칙**: 대기실은 튜토리얼처럼 *가르치지* 않는다. 그냥 참치를 놔두면 사람들이 알아서 집는다.
> 안내 팻말은 최소한만, 나머지는 서로 때리면서 배우게 둔다.

## 2. 컨셉 — "참치 제단"

**한 줄**: 숲속 들판 한복판, 돌로 둘러싸인 원형 공터에 낡은 나무 식탁이 놓여 있고,
그 위에 **냉동참치**가 성검처럼 안치되어 스포트라이트를 받고 있다.

- 엑스칼리버 / 성검 제단의 **정면 패러디**. 진지한 연출(빛기둥·돌기둥·원형 제단)에
  올려둔 물건만 **냉동참치**라서 웃긴다 — 이 게임의 톤 그 자체.
- 참치를 집는 순간 화면에 **"마검을 뽑았다!"** 가 뜬다. 그 순간부터 그 사람이 권력자다.
- 제단 조명은 참치가 사라지면 꺼진다. 누가 봐도 "마검이 나갔다"를 알 수 있다.
- 참치를 다시 식탁에 내려놓으면 조명이 돌아온다. (권력의 반납)

### 왜 하필 참치인가
이미 스테이지 1(집) 냉장고 안에 냉동참치 마검이 들어 있다. 대기실의 참치는 그것의
**상징 버전**이다 — 게임의 마스코트를 첫 화면에 못 박아두는 역할.

## 3. 공간 구성

```
                      ┌─────────────────┐
                      │   출발 게이트    │  ← 나무 아치 + 출발 발판(준비)
                      └────────┬────────┘
                               │  흙길
        허수아비 3            ★ 참치 제단 ★           모닥불 + 통나무
        (연습장)          (돌 원판 + 나무 식탁         (모여서 노는 곳)
                            + 냉동참치 = 마검)
                               │  흙길
                      ┌────────┴────────┐
                      │   스폰 지점 4    │  ← 조작 안내 팻말
                      └─────────────────┘
                   (사방은 나무로 둘러싸인 숲)
```

| 구역 | 내용 | 의도 |
|---|---|---|
| **참치 제단** (중앙) | 돌 원판 + 돌기둥 8개 + 나무 식탁 + 벤치 + **냉동참치** + 제단 스포트라이트 | 게임의 얼굴. 스폰하면 바로 눈에 들어온다 |
| **출발 게이트** (북) | 나무 아치 + 나무 발판(준비 트리거) | 준비 확인 |
| **허수아비 연습장** (서) | 허수아비 3개 — 마검으로 치면 넘어졌다 일어남 | 타격감 체험, 조작 학습 |
| **모닥불** (남서) | 모닥불 + 통나무 의자 | 잡담·대기 공간. 파티감 |
| **스폰 지점** (남) | 4인 스폰 + 조작 안내 팻말 | 제단을 정면으로 바라보게 배치 |
| **숲** (외곽) | 나무 24그루로 원형 차폐 | 맵 경계를 벽 없이 자연스럽게 |

## 4. 대기실에서 돌아가는 규칙

### 4.1 마검 (냉동참치)
- **딱 한 자루**. 제단 위에 놓여 있다.
- 집으면 손에 들린다 → 좌클릭 스윙 → **맞은 사람 즉사**.
- 죽은 사람은 **즉시 스폰 지점으로 부활**하고, 들고 있던 마검은 **그 자리에 떨어진다**.
  → 대기실에서부터 권력이 계속 이동한다. (스테이지 규칙 그대로)
- 리스폰 직후 짧은 무적이 있어 스폰킬은 안 된다.

> 대기실 죽음에는 **아무 페널티가 없다.** 그래서 마음 놓고 서로 때린다.
> 이것이 "대기실에서 이미 재밌다"의 핵심이다.

### 4.2 허수아비
- 마검을 휘둘러 맞히면 맞은 방향으로 **넘어졌다가 1초쯤 뒤 벌떡 일어난다**.
- 마검이 없어도 스윙 판정 자체는 들어가지만(빈손은 스윙 불가), 마검을 든 사람만 칠 수 있다.
- 연출 전용 — 점수·기록 없음. 순수하게 손맛 확인용.

### 4.3 출발 (준비 시스템)
1. 출발 게이트 앞 **나무 발판 위에 올라서면 준비 완료**.
2. 화면 하단에 `준비 2 / 4` 표시.
3. **접속자 전원이 발판 위에 있으면 5초 카운트다운** → 스테이지 1(집)으로 전환.
4. 카운트다운 중 **한 명이라도 내려오면 즉시 취소**.

> 발판을 쓴 이유: 버튼 UI보다 **몸으로 하는 합의**가 이 게임 톤에 맞고,
> "마검 든 놈이 발판 앞을 막고 안 비켜준다" 같은 병맛 상황이 저절로 생긴다.

## 5. 화면 흐름

```
MainTitle ──▶ Title 화면 : Game Start / Options / Quit
                 │
                 ├─ Game Start : 방 코드 입력 → [Host Game] / [Join]
                 │                  │
                 │                  ▼
                 │            Lobby (대기실 = Waiting Room)
                 │              Code : AOQNDXK      Member 2/5
                 │                  │ 전원 준비 → 5초
                 │                  ▼
                 │            NetworkDemo (집)
                 │                  │ 준비물 완료 → 현관
                 │                  ▼
                 │            Stage2_Campground (캠핑장)
                 │
                 └─ Options : Sounds / Language / Credit
```

- 기존에는 타이틀에서 곧장 집으로 들어갔다. 이제 **타이틀 → 대기실 → 집** 순서다.
- 대기실의 `NetworkBootstrap`(NetworkManager)이 씬 전환 후에도 유지되므로,
  집/캠핑장에는 여전히 부트스트랩을 따로 둘 필요가 없다.
- **방 정원은 5명**(호스트 포함). 대기실 스폰 지점 5개와 `maxConnections`가 같이 맞춰져 있다.

### 방 코드 (`RoomCode.cs`)

별도 매치메이킹 서버 없이, **IPv4 주소 32비트를 26진수로 담은 영문 7글자**를 코드로 쓴다
(26⁷ = 80억 > 2³²). 호스트가 방을 열면 자기 주소로 코드가 만들어지고, 친구가 그 코드를 적으면
주소로 되돌려 접속한다. 코드 대신 IP 주소를 직접 적어도 받아준다.

- 목업의 5글자(`AOQND`) 대신 7글자인 이유: IPv4 32비트는 영문 5글자(26⁵ ≈ 1,190만)에 담기지 않는다.
  5글자를 유지하려면 "호스트와 참가자가 같은 서브넷"을 가정해 뒷 두 옥텟만 담아야 하는데,
  가정이 깨지면 엉뚱한 곳으로 접속하므로 길이를 늘리는 쪽을 택했다.
- 같은 공유기(LAN) 안에서는 바로 연결된다. 인터넷 너머로 부르려면 포트포워딩이 필요하다.
- Phase 7에서 Steam 로비로 바꾸면 이 클래스만 로비 ID 기반으로 교체하면 된다.

## 6. 구현 구성

### 새 스크립트 (`Assets/Scripts/`)
| 파일 | 역할 |
|---|---|
| `LobbyManager.cs` | 준비 인원 집계·카운트다운·씬 전환 (서버 권한, `NetworkIdentity` 1개) |
| `LobbyReadyZone.cs` | 출발 발판. 로컬 플레이어가 영역 안에 있는지 주기 검사 → 준비 토글 |
| `LobbyAltar.cs` | 참치가 뽑히면 "마검을 뽑았다!" 연출 + 제단 조명/팻말 변경 (로컬 연출) |
| `PracticeDummy.cs` | 허수아비. 스윙에 맞으면 넘어졌다 일어남 (로컬 연출) |
| `WorldSign.cs` | 월드에 세우는 나무 팻말 텍스트(TextMesh) 폰트 보정 |

### 메인 화면 스크립트
| 파일 | 역할 |
|---|---|
| `MainMenu.cs` | 패널 전환(Title / Game Start / Options) + 호스트·참가 + 옵션 조작 |
| `RoomCode.cs` | 방 코드 ↔ IPv4 변환, 이 PC의 주소 조회 |
| `GameOptions.cs` | 마스터 볼륨·언어 저장(PlayerPrefs) |
| `GameLaunch.cs` | 타이틀 → 대기실로 넘길 실행 의도 + 방 코드 |

### 수정된 기존 스크립트
| 파일 | 변경 |
|---|---|
| `Weapon.cs` | `OnHeldChanged` 정적 이벤트 추가 (들림/내려놓임 시점을 제단 연출이 구독) |
| `ItemChecklist.cs` | 준비물이 하나도 없는 씬(대기실)에서 안내 문구 표시 |

### 에디터 도구
| 메뉴 | 하는 일 |
|---|---|
| `Tools > Lobby > Build Lobby` | 대기실 씬 전체 생성(환경·제단·참치·허수아비·발판·스폰·매니저) → `Assets/Scenes/Lobby.unity` 저장 → Build Settings 순서 정리 → 타이틀의 이동 대상 씬을 `Lobby`로 수정 |
| `Tools > Title > Setup Main Title` | 메인 타이틀 씬을 Title / Game Start / Options 3패널 구조로 생성 |

> 메인 화면 오브젝트 이름(`HostButton`, `CodeField`, `SoundsContent` 등)으로 `MainMenu.cs`가
> 계층을 찾는다. 빌더에서 이름을 바꾸면 `MainMenu`의 문자열도 같이 고쳐야 한다.

### 옵션 구현 범위
- **Sounds** — 마스터 볼륨 슬라이더. `AudioListener.volume`에 즉시 반영되고 PlayerPrefs에 저장된다. (동작)
- **Credit** — 제작 정보 텍스트. (동작)
- **Language** — 한국어/English 선택이 저장되지만, **문구 교체(로컬라이즈)는 아직 미구현**이다.
  화면에도 "준비 중"이라고 표시해 둔다. 로컬라이즈 레이어가 생기면 `GameOptions.Language`를 읽어 쓰면 된다.

> 프로젝트 규칙대로 **씬을 손으로 편집하지 않는다.** 대기실 수정은
> `Assets/Scripts/Editor/LobbyBuilder.cs`의 좌표/치수를 고치고 메뉴를 다시 실행한다.

### 전제 조건
- 대기실의 마검 원킬/리스폰은 기존 Phase 4·5 셋업에 의존한다.
  `NetworkDemo` 씬에서 `Phase 4 > Setup Weapon Sync`, `Phase 5 > Setup Combat`
  (NetworkPlayer 프리팹에 `PlayerHealth` 부착)을 먼저 실행해 둬야 한다.
- `Assets/Prefabs/NetworkPlayer.prefab`이 있어야 대기실의 NetworkManager가 플레이어를 스폰한다.
- 씬 전환 시 Mirror가 "Multiple NetworkManagers detected" 경고를 한 번 남긴다.
  대기실의 NetworkManager가 유지되고 다음 씬의 중복본이 스스로 파괴되는 정상 동작이다.
- 팻말 글자 크기(`Sign()`의 `characterSize`)와 제단 조명 세기는 눈으로 보고 조절하는 값이다.

### 네트워크 권한 모델 (기존 규칙 준수)
- 준비 상태·카운트다운·씬 전환: **서버 권한** (`Command(requiresAuthority = false)` + `SyncVar`)
- 마검 소지/스윙/원킬: 기존 `WeaponNetworkManager` + `PlayerHealth` 그대로 재사용
- 제단 연출·허수아비: 이미 동기화된 상태에 반응하는 **로컬 연출**이라 별도 동기화 없음

## 7. 검증 기준 (Acceptance)

- [ ] 타이틀에서 **Game Start → Host Game** 으로 방이 열리고, 대기실 왼쪽 위에 `Code : XXXXXXX` 가 뜬다
- [ ] 다른 PC에서 그 코드를 입력하고 **Join** 하면 같은 대기실로 들어오고 `Member 2/5` 로 바뀐다
- [ ] **Options**에서 볼륨을 바꾸면 즉시 반영되고, 게임을 껐다 켜도 유지된다
- [ ] 타이틀에서 호스트/참가 → **대기실**로 들어온다 (집이 아니라)
- [ ] 스폰하면 정면에 참치 제단이 보인다
- [ ] 참치를 집으면 손에 들리고 **"마검을 뽑았다!"** 문구 + 제단 조명이 꺼진다
- [ ] 마검으로 다른 플레이어를 치면 **즉사 → 즉시 리스폰**, 마검은 바닥에 떨어진다
- [ ] 허수아비를 치면 넘어졌다가 일어난다
- [ ] 발판에 올라서면 `준비 n/m` 이 올라가고, 전원 준비 시 5초 뒤 집으로 전환된다
- [ ] 카운트다운 중 한 명이 내려오면 취소된다
- [ ] 늦게 접속한 사람도 참치의 현재 소지 상태가 올바르게 보인다

## 8. 후속 아이디어 (지금은 안 함)

- **캠핑장 클리어 → 대기실 복귀** 루프 (현재는 캠핑장 → 집으로 루프)
- 대기실 전광판: 지난 판 킬 수 / MVP / "가장 먼저 배신한 사람" 같은 병맛 통계
- 플레이어 닉네임·색상 커스터마이즈 (대기실이 자연스러운 위치)
- 제단 참치를 뽑을 때 사운드(뽑는 소리 + 웅장한 합창) — 톤을 완성시키는 요소
- 대기실 미니게임: 참치 멀리 던지기, 허수아비 최다 타격 등
- 호스트 전용 "강제 출발" (인원이 안 모일 때)
