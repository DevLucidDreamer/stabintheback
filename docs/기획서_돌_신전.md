# 1단계 · 돌 신전

0단계 Lobby는 기존 씬을 유지한다. 플레이 경로는 MainTitle → Lobby → Stage1_StoneTemple → Stage2_BrokenBridge → Stage3_UndergroundAltar → Lobby이다.
기존 성채/연구동/캠핑장 씬은 보관만 하며 빌드 및 대기실 선택에서 제외한다.
1단계 완료 후 중앙 출구를 사용하면 2단계 폐광 돌다리로 이동한다. 2·3단계는 기획서_원정.md를 참고한다.

## 네 사람이 진행하는 순서

1. 입구: 한 명이 발판 0을 유지하고 나머지가 통과한다. 안쪽 레버 0이 문을 영구 고정한다.
2. 회랑: 입구 발판 1이 다리를 올린다. 건너편 발판 2로 역할 교대가 가능하다. 레버 1이 다리를 고정한다.
3. 추의 방: 석재를 클릭해서 들고 발판 앞에서 G로 내려놓는다. 사람도 문을 열 수 있다. 문 너머 레버 2에 도달하면 뒤쪽 발판 상태와 무관하게 합류 경로를 고정한다.
4. 쌍둥이 계단: 좌측 발판이 우측 길을, 우측 발판이 좌측 길을 연다. 중간 발판에서 역할을 교대한다. 끝 레버는 반대편의 귀환 경로를 고정하며 두 레버가 모두 당겨지면 다음 문이 열린다.
5. 성배실: 두 번째 석재로 다리를 유지하고 레버 5로 창살과 다리를 고정한다. 네 명이 서로 다른 네 발판에 1.25초 동안 서면 성배 봉인이 풀린다. 성배병을 주우면 출구가 열린다.

## 발판 안정성 규칙

- 플레이어 루트 Rigidbody는 kinematic, useGravity=false로 설정한다. 기존 프리팹의 동적 Rigidbody와 CharacterController 중력이 중복되어 바닥 아래로 가라앉던 원인을 제거한다. 런타임 초기화에도 동일한 보정을 적용한다.

- 서버가 0.05초마다 연결된 플레이어의 최신 Transform을 확인한다. Trigger Enter/Exit 횟수와 클라이언트의 자체 눌림 요청을 사용하지 않는다.
- CharacterController의 중심·높이·스케일에서 발 위치를 계산한다. 상체가 겹치는 것만으로는 눌리지 않는다.
- 회전된 발판은 로컬 좌표로 검사한다. 가장자리에는 이미 밟고 있던 사람에게만 8cm 여유를 준다.
- 한 사람은 한 번에 가장 가까운 발판 하나에만 기여한다. 사망·비활성·컨트롤러 비활성·연결 종료는 다음 표본에서 제외한다.
- 발판 시각 요소는 내려가지만 실제 바닥은 고정된다. 다리는 네트워크 시간으로 올라온 뒤 고정 콜라이더를 활성화한다. 떠날 때 1초 유예 후 내려간다.
- 눌림과 경로 고정은 별도 상태다. 진행 완료로 고정된 길은 다시 닫히지 않는다.
- 석재는 서버가 소유자와 놓인 위치를 동기화한다. 사망하거나 연결이 끊긴 운반자의 석재는 원래 자리로 돌아온다.
- 네 명 미만일 때는 마지막 봉인이 풀리지 않는다. 재접속 후 이어서 진행할 수 있다.
- 사망/낙하 복귀는 완료한 구간을 기준으로 한다. 성배병을 잃거나 소유자가 접속 종료하면 다시 회수할 수 있다.

## 조작과 오디오

- 좌클릭: 빈손 상호작용 / 무기 휘두르기
- 우클릭: 무기를 든 상태에서도 장치 조작
- G: 운반 석재 또는 무기 내려놓기
- ESC 설정: 전체 음량, 효과음, 배경음악 독립 조절
- 실제 플레이어 타격음은 서버의 명중 확정 RPC에서만 한 번 재생한다. 사망/리스폰 보호 중인 대상은 제외한다.
- 신전 구조물은 프로젝트에서 만든 기본 메시 조합이다. 외부 오디오는 CC0 확인 후 사용했으며 배포 고지에 원본 파일명을 기록했다.

## 성배병

원본: Assets/Models/성배병.blend (사용자 제공)

Tools/blend_import/export_chalice.py를 Blender로 실행해 실제 평가된 메시·머티리얼을 추출한다.
WeaponPrefabBuilder.BuildChalice가 Unity Mesh asset 및 ChaliceBottle.prefab을 생성한다.
플레이와 빌드에는 Blender가 필요하지 않으며 원본 .blend를 변경하지 않는다.

## 재생성 및 검사

Unity 메뉴 Tools / Stage / Build Stage 1 (Stone Temple): 새 신전만 재생성하고 대기실을 유지한다.
별도 유휴 검증 프로젝트에서 -executeMethod StoneTempleChecks.BuildAndCheckBatch:
맵 생성, 참조/머티리얼/오디오/스폰 검사, 발판 회귀 검사를 수행한다.
열려 있는 편집 씬은 additive 방식으로 보존한다.
