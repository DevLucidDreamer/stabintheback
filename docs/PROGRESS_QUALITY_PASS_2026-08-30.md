# 전체 완성도 개선 진행 기록

작성일: 2026-08-30

## UI 정리

- Vivox 연결 완료, PTT 안내, 음소거 전환 토스트를 플레이 화면에서 제거했다.
- 우측 하단에 52×52 크기의 마이크 아이콘만 유지한다.
  - 회색: 연결 대기
  - 초록: 연결됨
  - 하늘색: 현재 송신 중
  - 빨강과 사선: 음소거 또는 연결 실패
- 아이콘을 클릭하면 마이크 음소거를 전환할 수 있다.
- 최초 안내는 `ESC를 눌러 조작방법을 확인하세요` 한 줄만 3초간 표시한다.
- 상세 음성 모드, 음량, 조작법은 기존 ESC 메뉴에서만 표시한다.
- 로비에 이동·상호작용 표지판과 ESC·V·M·E·Tab 표지판을 분리 배치했다.

## Stage2 캠핑장

- 지면 크기를 70×70에서 140×140으로 확장했다.
- 중앙 화로 외에 다음 목적지를 추가했다.
  - 서쪽 관리소
  - 남쪽 피크닉 숲
  - 동쪽 호수 캠프와 확장된 호수·잔교
  - 북쪽 전망대
- 네 방향 산책로, 교차로 안내판, 4개 숲 고리, 170개 잡목·바위·덤불 배치를 추가했다.
- 재료를 11개에서 18개로 늘렸다.
  - 장작 6개
  - 고기 6개
  - 야채 6개
- 각 재료와 무기를 서로 다른 랜드마크와 외곽에 분산했다.
- 굽기 시간을 14초, 노을 전환을 15초로 조정했다.
- `Assets/Models/TENT.blend`와 `Assets/Models/chair.blend`를 실제 캠핑 프리팹에 사용한다.
- 모델 원점과 단위가 달라도 렌더러 경계를 기준으로 크기·바닥·콜라이더를 자동 보정한다.

예상 플레이타임 목표는 탐색 6~8분, 화로·조리 2~3분으로 총 8~12분이다. 실제 2~4인 플레이 결과에 따라 재료 위치 또는 조리 시간을 조정한다.

## Stage3 저주받은 성채

- 룬 입력을 4회에서 6회로 확장하고 양쪽 단서를 갱신했다.
- 봉인핵을 3개에서 4개로 늘렸다.
- 무기를 측면 가림벽 뒤쪽으로 옮겨 수색 과정이 생기도록 했다.
- 압력판 유지 3.5초, 쌍레버 8초, 최종 집결 3초로 조정했다.
- 현수막, 감옥, 잔해, 무기고 가구와 측면 관심 지점을 추가했다.

## Stage4 마검 탈출 성소

- 숨은 스위치를 3개에서 5개로 늘리고 탐색 미로 벽을 확장했다.
- 룬 입력을 4회에서 6회로 확장했다.
- 희소 마검은 2개로 유지하고 봉인핵은 4개로 늘렸다.
- 압력판 유지 3.5초, 쌍레버 9초, 최종 집결 3초로 조정했다.
- 가짜 무기 상자, 문지기 석상, 아치, 붕괴 잔해를 추가해 빈 복도 인상을 줄였다.

Stage3와 Stage4 모두 5~6개 협동 단계, 탐색, 분산 정보, 무기 경쟁을 포함해 첫 플레이 기준 약 8~12분을 목표로 한다.

## 남은 배포 조건

Unity Services의 Cloud 프로젝트 연결은 여전히 로그인된 Unity Hub/Editor에서 재연결해야 한다. 이 항목 때문에 정식 Release 빌드 검증기는 의도적으로 배포를 차단하고 있다. 로컬 품질 확인 빌드는 배포본이 아니다.

Cloud 연결 후 MPPM에서 Main Editor를 `Client and Server`, Player 2~4를 `Client`로 두고 아래를 실측한다.

- 각 스테이지의 2인·4인 실제 완료 시간
- 캠핑장 재료가 지형이나 모델 내부에 묻히지 않았는지
- Stage3·Stage4의 6단계 룬 단서 가독성
- 음성 아이콘의 연결·송신·음소거 색상 전환
- Relay 재접속과 Vivox 거리 감쇠
