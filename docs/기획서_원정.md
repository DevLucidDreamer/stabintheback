# 4인 원정 · 1~3단계

기존 대기실을 보존하고 세 개의 새 씬을 순서대로 연결한다. 기존 맵은 빌드에서 제외한다. 회색 CC0 석재, 높은 천장, 절제된 발판 표시, 기존 타격음·배경음악·WASTED 사망 표시는 공통으로 사용한다. 게임 내 해설 팻말은 만들지 않는다.

## 1단계 수정

레버를 건너편까지 도달했는데도 직전 발판이 해제됐다는 이유로 레버를 거절하던 조건을 제거했다. 접근 거리, 벽 차단, 순서, 중복 실행 검증은 유지한다. 추의 방에서 사람 대신 석재가 있어야만 레버를 고정할 수 있던 숨은 조건도 제거했다.

성배실 직전의 마지막 레버는 다리를 건넌 착지 지점 중앙으로 이동했다. 마지막 통로를 고정하면 성배실 입구가 열린다. 네 명이 각기 다른 봉인 발판에 서면 성배병 덮개가 열린다. 성배병을 획득한 뒤 중앙 출구로 2단계에 진입한다.

## 2단계 · 폐광 돌다리

- 입구의 네 채석장 석재를 운반해 다리 끝 작업대에 쌓는다. 석재 세 개당 3m 구간 하나가 완성된다.
- 총 24개로 길이 24m, 폭 6m 다리를 복구한다. 완성된 구간의 충돌 바닥은 고정되어 있으며 움직이지 않는다.
- 한 플레이어는 석재 하나만 운반한다. 중복 획득·중복 납품은 서버가 거절한다. G로 내려놓을 수 있고, 사망·연결 종료로 운반자가 사라지면 채석장으로 복구한다.
- 반대편 폐광 받침대의 랜턴은 실제 들고 휘두를 수 있는 마검이다. 휴대 조명도 함께 이동한다.
- 다리를 완성하고 랜턴을 획득하면 지하로 이어지는 문이 열린다. 출구 사용 시 네 명 모두 3단계로 이동한다.
- 다리 완성 후 사망 시 반대편 둑에서 복귀한다.

## 3단계 · 지하 제단

첫 방은 네 조각상을 같은 문자 받침대에 배치하는 퍼즐이다. 잘못 놓은 조각상은 다시 들 수 있다. 네 문자가 모두 일치하면 문이 영구 개방되며 조각상은 고정된다.

두 번째 방에는 문자 발판 여덟 개가 있다. 문 위에 새긴 네 문자와 같은 발판을 서로 다른 네 명이 1.5초 유지하면 다음 문이 영구 개방된다. 점프·사망·비활성·이탈은 발판 점유에서 제외한다.

마지막 방의 네 제단 기둥에 각각 손을 얹고 2초간 가까이 머무르면 의식이 완료된다. 한 사람이 여러 기둥을 대신할 수 없으며, 누군가 이탈하거나 죽으면 해당 손과 충전이 해제된다. 완료 시 빛기둥과 완료 표시가 나오고 출구로 대기실에 돌아간다.

## 에셋 및 재생성

새 외부 에셋은 추가하지 않았다. ambientCG CC0 텍스처와 기존 CC0 오디오를 재사용했다. 랜턴과 조각상은 이번 작업에서 만든 Unity 기본 메시 조합이다. 성배병은 기존 사용자 제공 모델의 변환 프리팹을 사용한다.

Tools / Stage / Build Stages 2 and 3 메뉴로 새 두 씬을 재생성한다. 전체 씬 생성과 자동 검증은 별도 유휴 프로젝트에서 ExpeditionChecks.BuildBatch를 실행한다. -expeditionPlayer 인수를 추가하면 Windows Development 빌드도 만든다.
