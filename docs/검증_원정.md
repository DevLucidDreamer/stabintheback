# 1~3단계 원정 검증 · 2026-09-05

## 자동 검사

기존 돌 신전 참조·발판 검사를 유지하고 최종 원정 검사 901개를 통과했다. 현재 프로젝트의 폰트도 최종 검증 및 빌드에 반영했다.

- 직전 발판이 꺼진 뒤에도 건너편 레버 6개 모두 동작한다. 중복 실행·원격 실행·벽 너머 실행은 거절한다.
- 새 씬의 스크립트와 머티리얼 참조, 각 4개 스폰을 검사했다.
- 석재 독점 소유, 접속 종료 시 회수, 24회 실제 납품 처리, 중복 납품 방지, 3개당 한 구간 완성, 반대편 체크포인트를 확인했다.
- 틀린 조각상 배치 거절과 올바른 네 자리 배치를 확인했다.
- 문자 발판 중복 점유·점프를 제외하고 네 개의 올바른 발판을 유지할 때만 제단 문이 열린다.
- 제단 이탈 시 손 등록과 충전 해제, 재참여 후 4인 완료를 확인했다.

## 실제 네트워크 검사

별도 검증 프로젝트에만 테스트 도구를 추가하고 Windows 게임 프로세스 4개를 loopback KCP로 연결했다.

1. 기존 대기실에서 4명 접속 후 1단계 진입.
2. 레버 6개 요청, 성배실 4인 발판 해제, 성배병 획득.
3. 출구 요청으로 네 프로세스가 모두 2단계 진입.
4. 네 플레이어가 돌아가며 석재 24개를 획득·납품, 돌다리 8구간 완성.
5. 폐광 랜턴 획득, 출구 요청으로 네 프로세스가 3단계 진입.
6. 조각상 4개 배치, 서로 다른 문자 발판 4개 유지, 제단 4곳 상호작용.
7. 네 프로세스 모두 마지막 의식 완료를 관찰하고 출구를 사용해 기존 대기실 복귀.

이 검사는 로컬 플레이어 위치를 자동 배치한 뒤 실제 네트워크 요청을 보내고 모든 클라이언트의 상태를 확인했다. 조작감을 확인하는 수동 플레이나 인터넷 지연·Relay·Vivox 검사를 대신하지 않는다. loopback 검사에서 Vivox 서비스 오류가 기록됐으며 음성 연결은 이번 검증 대상이 아니다.

테스트 도구는 원본 프로젝트와 사용자용 실행 파일에 포함하지 않는다. 로그는 Logs/expedition-checks.log, Logs/expedition-peer0.log ~ expedition-peer3.log에 남겼다.
