# 저주받은 성채 — 협동 탈출 스테이지

## 핵심 경험

플레이어가 같은 일을 반복하는 수집형 협동이 아니라, 서로 다른 위치에서 정보를 보고 역할을 나누며 타이밍을 맞추는 10~15분짜리 탈출전이다. 위치 기반 Vivox 음성은 단순 편의 기능이 아니라 룬 단서 전달과 쌍레버 카운트다운의 실제 플레이 수단이 된다.

## 진행 구조

1. **균형의 사슬** — 서로 다른 두 사람이 떨어진 압력판을 2.5초간 동시에 밟는다. 1인 에디터 테스트에서는 두 판을 차례로 밟으면 잠긴다.
2. **갈라진 예언** — 서쪽 벽에는 `달 → 불`, 동쪽 벽에는 `가시 → 눈` 단서가 있다. 팀이 정보를 합쳐 중앙 룬을 `달 → 불 → 가시 → 눈` 순서로 누른다. 실패하면 처음부터 다시 입력한다.
3. **쌍둥이 심장** — 시야를 가르는 벽 양쪽의 레버를 서로 다른 사람이 7초 안에 당긴다. 위치 음성으로 준비와 실행 타이밍을 맞춘다.
4. **마검의 회랑** — 무기고에서 마검 역할의 음식 무기를 나누어 들고 세 봉인핵을 타격한다. 맨손으로는 파괴되지 않는다.
5. **생환의 진** — 접속한 전원이 마지막 원 안에 2초간 머물러야 승리한다. 앞서 간 플레이어가 동료를 버릴 수 없다.

## 레벨 디자인 원칙

- 관문과 보라·청록·붉은 강조색으로 다음 목표가 멀리서도 읽힌다.
- 각 퍼즐 앞 팻말은 규칙만 알려 주고 답은 알려 주지 않는다.
- 룬 단서는 양쪽 끝에 갈라 놓아 한 화면에서 동시에 읽을 수 없다.
- 쌍레버 중앙 장벽은 상대의 손동작 대신 음성을 쓰게 만든다.
- 마검은 4개를 제공해 2~4인이 역할을 나누되, 한 명이 독점해도 다른 무기가 남는다.
- 최종 집결은 탈락자나 길을 잃은 동료를 기다리게 만들어 협동의 결말을 보장한다.

## 실패와 회복

- 압력판에서 발을 떼면 진행도가 서서히 감소한다.
- 룬 오답은 입력만 초기화하며 플레이어를 처벌하지 않는다.
- 레버 제한 시간이 끝나면 두 레버가 원위치로 돌아간다.
- 봉인핵은 파괴 상태가 서버에 저장되어 재타격할 필요가 없다.
- 모든 핵심 상태는 서버 권한으로 동기화되고, 씬 진행 중 참가한 클라이언트도 현재 단계를 받는다.

## 플레이테스트 체크리스트

- 1인 호스트: 압력판 순차 보조, 레버 순차 보조, 룬/봉인/탈출까지 완주
- 2인: 같은 사람이 양쪽 레버를 작동할 수 없는지 확인
- 2~4인: 한 명이 탈출진 밖에 있으면 승리하지 않는지 확인
- 룬 오답 후 HUD 진행도가 0으로 돌아가는지 확인
- 무기를 든 플레이어만 봉인핵을 파괴하는지 확인
- 늦게 참가한 클라이언트에서 열린 관문과 파괴된 핵이 동일하게 보이는지 확인
- 승리 8초 후 전원이 Lobby로 복귀하고 Vivox 채널 상태가 정상 전환되는지 확인

## 재생성

Unity 메뉴 `Tools > Stage > Build Stage 3 (Cursed Fortress)`를 실행하면 씬을 다시 생성한다. 생성 결과는 `Assets/Scenes/Stage3_CursedFortress.unity`이며, 빌드 순서는 `MainTitle → Lobby → Stage3_CursedFortress → Stage2_Campground`로 정리된다.
