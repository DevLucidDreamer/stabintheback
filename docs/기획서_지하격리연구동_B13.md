# 지하 격리 연구동 B-13 — 맵 전면 리워크 기획

> 대상 씬: `Assets/Scenes/Stage4_MagicSwordEscape.unity`  
> 방향: 4~8인 1인칭 협동·배신 파티게임 / 예상 플레이 시간 12~18분

## 1. 한 줄 경험

서로 다른 정보를 가진 플레이어들이 폐쇄된 지하 연구시설의 여섯 실험실을 함께 통과하지만,
마지막 격리 구역에서 발견한 단 두 개의 마검 때문에 협력 관계가 언제든 깨지는 멀티플레이 탈출전이다.

## 2. 리워크 목표

- 기존 집·야외·성채 테마와 분리된 스테이지를 **하나의 일관된 연구시설 세계관**으로 묶는다.
- 단순히 버튼을 차례대로 누르는 맵이 아니라, 매 구역에서 플레이어의 위치와 역할이 갈리게 만든다.
- 영화 《큐브》에서 연상되는 폐쇄감·반복 기하학·방마다 다른 위험 신호를 차용하되, 구조와 퍼즐은 본 게임에 맞게 새로 설계한다.
- 회색만 사용해 밋밋해지는 것을 피하기 위해 **회색 85% + 상태색 10% + 오염/마모 5%** 원칙을 사용한다.
- 실패해도 판이 막히지 않고 즉시 다시 시도할 수 있게 한다.

## 3. 공간 구성

맵은 지하 연구동의 정육면체 셀 여섯 개와 그 사이의 기밀문으로 구성된다.

```text
[B-01 검역] → [B-02 관찰] → [B-03 운송] → [B-04 제어]
                                                ↓
[B-06 탈출] ← [B-05 격리] ←────────────────────┘
```

실제 플레이 동선은 직선으로 읽히지만, 각 셀 안에서는 파티가 좌우·전후로 갈라진다.
천장이 낮고 다음 방이 기밀문 너머로만 보여서 폐쇄감을 유지하며, 문이 열릴 때마다 짧은 안도와 다음 목표의 실루엣을 제공한다.

| 구역 | 핵심 행동 | 멀티플레이 역할 | 상태색 |
|---|---|---|---|
| B-01 검역실 | 숨은 전력 단자 5개 복구 | 흩어져 수색하고 발견 위치 공유 | 주황 |
| B-02 관찰실 | 양쪽 관찰 기록을 조합해 6자리 기호 입력 | 기록 판독 2명 + 입력 담당 | 청록 |
| B-03 시료 운송실 | 서로 다른 두 발판을 3.5초 유지 | 좌우 운송로 동시 점유 | 황색 |
| B-04 중앙 제어실 | 가벽 뒤 두 차단기를 9초 안에 작동 | 음성으로 카운트다운 | 적색 |
| B-05 격리 보관실 | 숨겨진 마검 2개로 격리핵 4개 파괴 | 무기 소유자 호위 또는 배신 | 적색/백색 |
| B-06 비상 승강기 | 전원 3초간 승강기 안 집결 | 낙오자 확인, 마지막 대치 | 녹색 |

## 4. 한 판의 감정 곡선

1. **불안** — 동일한 회색 패널과 감시 장치 속에서 자신이 실험 대상임을 인지한다.
2. **분산** — 첫 방에서 빠르게 흩어지고, 숨은 단자를 찾으며 자연스럽게 대화를 시작한다.
3. **의존** — 한 사람이 볼 수 없는 기록과 혼자 유지할 수 없는 장치로 협력을 강제한다.
4. **긴장 상승** — 제한 시간 차단기에서 실패와 재시도가 빠르게 반복된다.
5. **권력 이동** — 격리 보관실에서 마검 두 개만 풀리며 협동이 심리전으로 변한다.
6. **마지막 선택** — 모두가 모여야 문이 닫히므로 마검 소유자도 다른 사람을 완전히 버릴 수 없다.

## 5. 시각 언어

### 재질과 색

- 바닥: 짙은 흑연색 미끄럼 방지 패널, 방 경계마다 흰색 셀 번호.
- 벽: 중명도 회색 콘크리트 패널 + 어두운 금속 프레임.
- 천장: 노출 배관과 반복되는 백색 형광등. 주요 장치 위에만 상태색 조명.
- 문: 두꺼운 금속 기밀문, 중앙 상태 바가 현재 퍼즐의 색을 표시.
- 경고: 노랑·검정 스트라이프는 문턱, 추락 위험, 격리 장치에만 사용.
- 오염: 녹색이 아니라 검갈색 누수 자국과 붉은 산화 흔적으로 연구시설의 노후도를 표현.

### 형태 규칙

- 모든 방은 같은 30m × 20m × 6m 모듈을 기본으로 해 반복 공간의 불안을 만든다.
- 방마다 바닥 패턴과 내부 프레임 방향만 바꿔 길 찾기는 가능하게 한다.
- 상호작용 가능한 장치는 허리~가슴 높이에 놓고, 작은 발광 패널과 번호를 붙인다.
- 장식물은 이동 폭 2.2m 이상, 주요 문 앞 4m 이상의 전투 공간을 침범하지 않는다.

## 6. 플레이 규칙과 회복성

- 모든 핵심 진행은 서버 권한으로 판정하고 중도 참가자에게 현재 상태를 동기화한다.
- 룬 오답은 입력 진행만 초기화한다.
- 압력판에서 내려오면 진행도가 서서히 감소한다.
- 제한 시간 안에 차단기를 맞추지 못하면 차단기만 원위치로 돌아간다.
- 파괴한 격리핵은 다시 살아나지 않는다.
- 사망자는 즉시 리스폰하며 들고 있던 마검은 사망 위치에 떨어진다.
- 1인 테스트에서는 발판과 차단기를 순서대로 조작할 수 있지만, 2인 이상에서는 서로 다른 플레이어가 필요하다.

## 7. 플레이테스트 기준

- 첫 플레이에서도 30초 안에 B-01의 첫 단자를 한 개 이상 발견한다.
- 4인 파티가 어느 한 사람에게만 의존하지 않고 최소 두 번 이상 자연스럽게 역할을 나눈다.
- 각 기밀문이 열린 뒤 다음 목표를 5초 안에 시각적으로 찾을 수 있다.
- B-05 진입 전까지 PvP가 진행을 영구 방해하지 않는다.
- 마검을 독점한 플레이어가 있어도 다른 마검 또는 사망 드롭으로 권력 이동이 가능하다.
- 8인에서도 주요 통로가 막히지 않고, 2인에서도 모든 퍼즐을 정상 완료할 수 있다.
- 한 판이 12~18분 안에 끝나며 같은 퍼즐의 실패 재시도가 20초를 넘기지 않는다.

## 8. 구현 범위

이번 리워크에서는 기존 네트워크 상태 머신과 상호작용 컴포넌트를 유지하고 다음을 교체한다.

- Stage4의 전체 건축, 조명, 머티리얼, 장식, 표지판, 오브젝트 배치
- 스테이지/HUD/목표/알림 명칭을 연구시설 세계관으로 변경
- 로비의 스테이지 표시명을 `지하 격리 연구동 B-13`으로 변경
- 자동 씬 생성 메뉴를 `Tools > Stage > Build Stage 4 (B-13 Laboratory)`로 변경

씬 파일 이름은 기존 연결과 빌드 설정을 깨지 않기 위해 유지한다.
